🤖 ربات فوروارد خودکار تلگرام
================================

این ربات پیام‌های جدید از کانال‌ها/گروه‌ها رو خودکار به مقصد فوروارد میکنه.

📌 ویژگی‌ها:
• فوروارد خودکار پیام‌های جدید
• فیلتر بر اساس کلمات کلیدی
• حفظ یا حذف فرستنده اصلی
• دستورات مدیریتی (/status, /sources, /dest)

⚙️ نصب:
۱. از @BotFather یه ربات جدید بساز
۲. توکن ربات رو کپی کن
۳. ربات رو به کانال‌های مبدأ ادمین کن
۴. ربات رو به کانال مقصد ادمین کن
۵. توکن رو توی فایل bot.py قرار بده یا متغیر محیطی تنظیم کن

🚀 اجرا:
python3 bot.py

📋 تنظیمات در فایل bot.py:
• BOT_TOKEN: توکن ربات
• SOURCE_CHANNELS: لیست chat_id کانال‌های مبدأ
• DESTINATION_CHANNEL: chat_id کانال مقصد
• KEYWORD_FILTER: فیلتر کلمات کلیدی (اختیاری)
• KEEP_SENDER: حفظ فرستنده اصلی (True/False)

📝 مثال:
SOURCE_CHANNELS = [-1001234567890, -1009876543210]
DESTINATION_CHANNEL = -1001111111111
KEYWORD_FILTER = ["هوش مصنوعی", "AI"]
KEEP_SENDER = True
